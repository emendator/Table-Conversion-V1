## 这个工具是干什么的

你有一批**客户发来的表格**，每张表格的列名、列顺序都不一样。

公司有一份**标准的参考模板**（「参考.xlsx」），规定了统一的列名和格式。

这个工具就是帮你**自动把客户的表格转成公司标准格式**，省去手动复制粘贴的麻烦。

**它能做什么：**

- 🤖 用 DeepSeek V4 Flash AI 自动匹配列名——不仅看表头，还会对比**列里的实际数据**来精准判断
- 🧠 **三级匹配策略**——先按映射库记录匹配，再精确匹配（列名完全相同），最后交给 AI/本地引擎处理剩余列，越用越准、越快
- 🧩 **不用 AI 也能智能匹配**——内置本地匹配引擎，通过列名语义、领域关键词、数据类型综合评分，离线也能用
- 🧠 **映射历史自动学习**——你手动调整过的映射关系会被记录下来，下次自动优先使用
- 📚 **映射匹配库管理**——网页上可增删改查、多选批量删除、导出 Excel / 导入 Excel/CSV，重复数据自动确认（覆盖/跳过/取消）
- 🔀 **重复列名编号**——源表/参考表出现同名列时按顺序编号区分（金额、金额(2)），输出文件仍保留原始列名
- 📝 **公式列智能处理**——自动识别源表/参考表公式列，映射时可选"用数据/保留公式/用源公式"，输出不破坏公式
- 📦 **一次上传多个表格**，自动合并成一个结果文件
- 🖼️ 自动把客户表格里的产品图片搬到结果表格中，缩放居中
- 📊 转换完成后可**在线预览**原始表格和结果表格的对比
- 🔧 映射关系**可手动调整**，源列和目标列都能改
- 🔐 **多账号登录/注册**——内置最高级管理员，支持管理员/用户邀请注册，三级权限
- ⏰ **账户有效期管理**——邀请码可设置注册账户的有效期天数；账户到期后禁止登录，并在登录时**醒目提醒使用者**联系管理员续期
- 🏢 **公司数据隔离**——映射库按「公司名 + 公司数据库密码」隔离，不同公司数据互不可见，杜绝冒用
- 🔒 **数据加密存储**——账户、密码、API Key 等敏感数据加密后存于 `data/users/`，磁盘上不落明文

## 用户系统（账号与权限）

工具支持多账号登录，数据按公司隔离。打开 `http://127.0.0.1:3002` 会先进入登录页。

### 账号与角色

| 角色 | 说明 |
| --- | --- |
| 最高级管理员（admin） | 内置账号，管理所有账号/公司/邀请码，可生成管理员与用户邀请码 |
| 管理员（manager） | 通过一级邀请码注册；可创建新公司、生成用户邀请码、管理自己创建的账号 |
| 用户（user） | 通过二级邀请码注册；只能使用转换功能，加入已有公司 |

内置最高级管理员：**用户名 `admin`，密码 `***REMOVED***`**，公司「***REMOVED***」（公司数据库密码 `***REMOVED***`）。登录后可在「用户管理」页修改公司数据库密码。

### 注册

1. 点击登录页「注 册」标签
2. 填写用户名、密码、邮箱、邀请码（由管理员分发）
3. 选择公司归属：
   - 🏢 **新注册公司**：填写新公司名 + 设置公司数据库密码（**仅管理员可创建新公司**，普通用户填不存在公司会被拒绝）
   - 🔑 **登录已有公司**：填写已有公司名 + 该公司数据库密码（密码校验通过才可加入）
4. 提交后自动登录

> ⚠️ 公司名注册后不可修改，请仔细填写。

### 游客登录

- 登录页提供「**以游客身份登录**」入口，无需账号密码即可体验全部功能
- 游客权限：**导入表格、表格转换、使用映射库**，并需在「⚙️ API 设置」中**自行配置自己的 API Key** 才能使用 AI 匹配
- 游客**没有用户管理界面**（无邀请码/账号/公司管理权限），数据按独立隔离键存储，与其他公司互不可见
- **退出登录后自动清除全部使用痕迹**：游客账号、映射库（图片库）数据、API Key、本次上传/输出文件均被删除；令牌过期（24h）或服务重启后也会自动清理
- 游客账号不可通过用户名密码再次登录

### 邀请码

- 管理员可在「用户管理」页生成邀请码（选择角色 + 账户有效期截止日期）
- **有效期截止日期 = 用该邀请码注册的账户的到期时间**（留空 = 永久；账户到期后将被**禁止登录**，登录时会有醒目的过期提醒，可被管理员延长或清除）
- 邀请码本身不过期，**无论是否使用都可随时删除**

### 账号管理

- 账号管理**仅显示自己创建的账户**（通过自己发出的邀请码注册的账号）
- 可延长账号有效期、清除账号（清除管理员时其下用户级联删除）

### 公司数据库密码

- 映射库按「公司名 + 公司数据库密码」隔离，即使知道公司名，没有密码也无法访问该公司数据
- 公司数据库密码由该公司管理员创建/修改（最高级管理员可管理任意公司），修改后映射库数据自动迁移、不受影响
- 新用户加入公司必须填写正确的公司数据库密码
- **当公司名下没有任何注册账号时，该公司的公司名、密码及对应映射库（图片库）数据会自动清理删除**（内置最高级管理员公司除外）

## 云服务器部署

项目已正式部署到云服务器，公司同事可通过浏览器直接访问使用：

- **访问地址**：`http://***REMOVED***:8080`
- **部署架构**：Nginx(8080) 托管前端静态文件，并将 `/api` 反向代理到后端 FastAPI(`127.0.0.1:8004`)，后端由 systemd 守护、开机自启
- **数据存储**：全部业务数据（用户账号、映射库、输出等）存放在服务器 `/opt/table-converter/data/`
- **更新方式**：本地改完代码 `git push` 后，服务器执行 `git pull` + `deploy/update.sh` 即可生效

> 📄 **完整部署 / 更新 / 备份 / 排障文档**：见 [云服务器部署指南](docs/部署/云服务器部署指南.md)，含一键部署脚本 `deploy/deploy.sh`。

### 端口分配（防止与其他工具冲突）

| 服务 | 端口 | 说明 |
| --- | --- | --- |
| Nginx（对外） | 8080 | 公网访问入口，需在云安全组放行 |
| FastAPI 后端（内网） | 8004 | 仅 `127.0.0.1` 监听，由 Nginx 反代 |

> 后续其他工具建议按 `8081 / 8005`、`8082 / 8006` … 递增分配，避免端口冲突。

## 本机运行（便携方式）

> 💡 以下为**本机 / 便携运行**方式（开发调试、离线使用）。正式使用请直接访问上面的云服务器地址。

### 1. 安装 Python

如果电脑上还没有 Python，请从 [python.org](https://www.python.org/downloads/) 下载安装。

> ⚠️ 安装时**一定要勾选**「Add Python to PATH」！

### 2. 安装 Node.js

前端界面基于 React，需要 **Node.js 运行环境**。请从 [nodejs.org](https://nodejs.org/) 下载并安装 LTS 版本。

> ⚠️ 安装时使用默认选项即可，安装程序会自动把 `node` 和 `npm` 加入 PATH。

安装完成后，打开命令提示符验证：

```cmd
node --version
npm --version
```

如果能看到版本号（例如 `v18.x.x`），说明安装成功。

### 3. 双击启动（便携方式 — 推荐）

将整个项目文件夹复制到任意电脑后（例如用 U 盘），找到 **`启动.bat`** 并**双击运行**。

`启动.bat` 会自动调用 PowerShell 脚本（`launcher.ps1`），完成以下操作：

1. ✅ 检测 Python 和 Node.js 是否已安装
2. ✅ 自动创建 Python 虚拟环境（如不存在）
3. ✅ 自动安装 Python 依赖（pandas、fastapi、openpyxl 等）
4. ✅ 自动安装前端依赖（React、Vite 等）
5. ✅ 启动后端 FastAPI 服务（端口 8004）
6. ✅ 启动前端开发服务器（端口 3002）
7. ✅ 自动打开浏览器

> 如果双击没反应，右键选择「以管理员身份运行」。

**手动停止**：在启动窗口按任意键即可停止所有服务。

### 4. 看到这个界面就成功了

```
============================================================
  📊 表格转换工具 - React + FastAPI 架构
============================================================
  🔧 后端 API 服务: http://127.0.0.1:8004
  🖥️  前端界面:    http://127.0.0.1:3002
  📖 API 文档:     http://127.0.0.1:8004/docs
============================================================
```

打开浏览器，在地址栏输入 `http://127.0.0.1:3002`，就能看到操作页面。

### 5. 文件放哪里

根据使用方式不同：

- **🖥️ Web 界面（推荐）**：直接在页面上传即可，文件无需放入特定文件夹。
  - 上传后文件会暂存在 `data/uploads/` 目录，关闭工具时自动清理。
  - 参考模板只需上传一次，后续可随时切换。
- **⌨️ 命令行**：参考模板和原始表格路径都直接写在命令里，文件可放任意位置。
  - 例如：`python backend/main.py D:\模板\参考.xlsx D:\客户文件\客户A.xlsx`
  - 项目自带的示例表格放在 `表/原始表` 和 `表/参考表` 目录下统一管理。

> 💡 `表/` 目录是存放示例/业务表格的目录，Web 模式下文件位置不受限制。

## 如何使用（图文教程）

### 第一步：上传文件

打开页面后，你会看到两个上传区域：

| 左侧 | 右侧 |
|------|------|
| **原始表格**（客户发来的） | **参考模板**（公司标准格式） |

**操作方法（任选一种）：**

- 直接把文件**拖拽**到对应的区域
- 或者**点击**上传区域，在弹出的窗口中选择文件
- 左侧原始表格可以**一次选择多个文件**（按住 Ctrl 多选），或后续点击「➕ 添加文件」追加

上传成功后，会显示文件列表信息。

> 💡 参考模板只需上传一次，所有原始表格都按这个模板转换。

### 第二步：智能列匹配

两个区域都有文件后，页面会出现「🤖 AI 智能列匹配」区域。

1. **匹配方式选择**：
   - 打开「使用 DeepSeek AI 匹配」开关 → 使用 AI 进行语义匹配（更精准）
   - 关闭开关 → 使用内置本地匹配引擎（离线可用，无需网络）
2. 点击 **「🔍 开始匹配」** 按钮
3. 系统会**同时分析表头名称和列里的实际数据**，进行智能配对

> 💡 **三级匹配策略**（与是否开启 AI 无关）：
>
> 1. **映射库匹配** — 优先使用你历史确认过的映射关系
> 2. **精确匹配** — 源列与参考列列名完全相同的直接对应
> 3. **AI / 本地匹配** — 剩余列交给 AI 语义匹配（或离线本地引擎）
>
> 这样系统**越用，AI 需要处理的列就越少，等待时间也越短**。

> 💡 **本地匹配**内置了 9 大领域词典（型号、价格、图片、品牌、品类等）和数据类型推断，即使不用 AI 也能得到合理的匹配结果。

匹配完成后，你会看到一个映射表格：

```
匹配度    原始表格列名        →    参考表格列名        操作
─────────────────────────────────────────────────────────
  高      大客户代发价        →    新进货价           删除
  高      序号               →    序号               删除
  中      产品               →    型号               删除
  高      图片               →    图片               删除
```

> 💡 **公式列标注**：若某列是公式列，列名旁会显示小字标签 **ƒ 公式**（源表或参考表的公式列都会标注），下拉选项内也会带 `ƒ` 前缀，方便识别。

### 第三步：检查和调整

- 如果某条匹配**不对**，点击下拉框手动更改
- 如果 AI **漏掉了某列**，点击「➕ 手动添加映射」补充
- 不需要的映射点击「删除」
- **源列名**（左侧）和**目标列名**（右侧）都可以点击下拉框切换

**公式列处理**：如果源列或参考列是公式列，会多出一列「公式处理」下拉选项，按情况选择：

| 情况 | 可选处理方式 |
| ------ | ------------- |
| 仅源列为公式列 | 用源数据（取计算值）/ 用源公式（保留计算公式） |
| 仅参考列为公式列 | 保留公式 / 用数据覆盖 |
| 源列与参考列均为公式列 | 保留参考公式 / 保留源公式 |

> 💡 默认值已按常见需求预设，如无特殊需要可直接用默认。

**重复列名**：如果表格中有多列同名（如两个「金额」），会自动按顺序编号为 `金额`、`金额(2)`，方便区分；下载的输出文件仍保持原始列名不编号。

### 第四步：执行转换

确认映射无误后，点击 **「🚀 开始转换」** 按钮。

几秒后转换完成，页面会显示：

- 📥 **下载转换结果** — 点击下载最终表格
- 🔍 **表格内容预览** — 可以在页面上直接查看结果

### 第五步：检查结果

打开下载的 `.xlsx` 文件，检查：

1. 数据是否正确填入对应列
2. 图片是否正常显示
3. 公式列是否自动计算

> 💡 如果结果不理想，可以点击「🔄 转换新文件」重新来过。

## 常见问题

### Q: 登录时提示「您的账户已过期」？

说明您的账户**有效期已到期**，已被禁止登录。登录页会醒目提示您的过期时间。请联系给您分发邀请码的管理员，在「用户管理 → 账号管理」中为您的账号点「延长」续期，即可恢复登录。

### Q: AI 匹配结果是 0 个列？

可能是网络问题导致 AI 返回不完整。请尝试：

1. **关闭 AI 开关再匹配**——本地匹配引擎无需网络，也能给出合理的匹配结果
2. 检查电脑是否能正常访问 `https://api.deepseek.com`
3. 重试一次

### Q: 转换后图片位置不对？

这通常是源文件中图片的锚点格式特殊。工具已支持两种主流图片格式（单元格嵌入和浮动锚点），如仍有问题请在 Excel 中将源文件另存为 `.xlsx` 格式后重试。

### Q: 点击上传没反应？

1. 刷新页面（Ctrl+F5 强制刷新）
2. 确认终端窗口没有关闭（后端和前端两个服务必须保持运行）
3. 如果提示网络错误，说明后端 FastAPI 服务已停止。
   - 重新双击 `启动.bat`
   - 或用任务管理器杀掉所有 `python.exe` 和 `node.exe` 进程后再启动

### Q: 浏览器打开后页面空白/加载不出来？

可能是 Vite 开发服务器启动较慢。请确认终端中有如下输出：

```
VITE v8.1.4  ready in xxx ms
  ➜  Local:   http://localhost:3002/
```

如果看到 `Network: http://127.0.0.1:3002/` 则说明可以正常访问。若始终空白的黑尝试强制刷新（Ctrl+F5）。

### Q: 浏览器提示 `127.0.0.1:3002 无法访问`？

Vite 默认可能绑定到 IPv6，在 `vite.config.js` 中已配置 `host: '0.0.0.0'` 确保同时监听 IPv4。
如果仍有问题，请确认没有其他程序占用了 3002 端口。

### Q: 控制台报 `Encountered two children with the same key` 警告？

这是 React 的 key 唯一性警告。当参考模板中有多列同名（如多列「毛利率」「销售折扣」）时会出现。
不影响功能正常运行，已在前端代码中修复此问题。

### Q: 转换后有些列是空的？

检查映射表，确认所有需要的列都已正确配对。必要时使用「手动添加映射」补充。

### Q: 多个原始表格能一起处理吗？

可以！上传时按住 Ctrl 多选文件，或上传后点「➕ 添加文件」追加。工具会自动逐个匹配并合并成一个结果文件。

### Q: 换了一份完全不同的参考模板能用吗？

能。**公式列、毛利率列等全部由工具自动从参考模板中识别**，不需要修改任何代码。

### Q: 映射历史记录存在哪里？能清空吗？

映射历史记录保存在项目 `data/映射历史记录_{key}.json` 文件中（`{key}` 为当前登录用户所属公司的隔离键，按公司分开存储）。文件为明文 JSON，可直接用记事本打开查看或编辑；如需清空某公司的历史记录，删除对应文件即可（下次使用时自动重建）。

### Q: 怎么管理映射匹配库（查看/删除/导入导出）？

点击页面顶部的 **「📚 映射匹配库」** 按钮进入管理页：

- 🔍 搜索、✏️ 编辑、🗑️ 删除单条记录
- ✅ 多选 + 批量删除
- 📤 **导出**为 Excel 表格（.xlsx）
- 📥 **导入** Excel / CSV 表格（自动识别「源列名」「目标列名」列）
- 每条记录显示**来源**（AI自动 / 手动 / 导入）和使用次数

### Q: 表格里有同名列（如两个「金额」）怎么办？

工具会自动按出现顺序编号：第一个叫 `金额`，第二个叫 `金额(2)`，第三个叫 `金额(3)`，方便在匹配时区分。**下载的输出文件仍然使用原始列名**（两个都叫「金额」），不影响参考模板格式。

### Q: 公式列匹配时选错了处理方式怎么办？

在「映射预览与调整」步骤，每行公式列右侧都有「公式处理」下拉框，可随时修改：

- **用源数据** = 把源表这一列的计算结果填进去
- **用源公式** = 把源表的计算公式搬过去（会按列映射调整）
- **保留公式** = 使用参考模板里该列的公式
- **用数据覆盖** = 用源表数据覆盖参考公式

### Q: 关闭 AI 匹配后匹配效果好吗？

本地匹配引擎通过**列名语义分析 + 领域关键词匹配 + 数据类型推断 + 字符相似度**的综合评分算法进行匹配。对于常见的列名（序号、图片、型号、价格、品牌、备注等）准确率很高。如果遇到匹配不准的情况，可以手动调整，调整结果会被保存到历史记录中，下次自动优先使用。

## 简单维护指南

> 💡 **不需要懂编程就能修改以下配置。** 用记事本打开对应文件，修改数字或文字，保存即可。

### 1. 修改 DeepSeek API 密钥

API 密钥**不再写在代码里**，而是在网页上配置：

1. 打开网页，点击右上角 **「⚙️ API 设置」** 按钮
2. 输入你的 DeepSeek API Key（以 `sk-` 开头），点击保存
3. 未配置 Key 时，使用「AI 匹配」会被强制要求先填写

安全说明：

- API Key 会**加密**后**按账户**存储在本机项目 `data/users/api_keys.json`，网页上只显示掩码（如 `sk-****abcd`），不会明文泄露
- 解密密钥保存在 `data/.ai_secret`（请勿提交到 Git，已在 `.gitignore` 中排除）
- token 消耗统计**按账户分账户独立记录**（不同账号互不影响）
- 账户数据（用户 / 邀请码 / API Key / 公司）加密存储于 `data/users/`，删除后下次启动自动重建（仅保留最高级管理员）
- 与映射匹配库（`data/映射历史记录_{key}.json`，按公司隔离键命名）一致，统一存放在项目 `data/` 目录，被删除后会在下次使用时自动重新创建

> ⚠️ **安全提醒**：API 密钥是花钱买的，不要发给别人，也不要提交到代码仓库！

### 1.1 修改 DeepSeek 模型

用记事本打开 `backend/config.py`，找到：

```python
DEEPSEEK_MODEL = "deepseek-v4-flash"       # 模型名称
```

可用的模型名（参见 [DeepSeek 官方文档](https://api-docs.deepseek.com/zh-cn/)）：

- `deepseek-v4-flash` — 快速响应，适合日常使用
- `deepseek-v4-pro` — 更精准，响应稍慢

### 2. 账号与公司密码管理

账号与公司密码管理均在网页「用户管理」页完成（仅最高级管理员 / 管理员可见）：

- **生成邀请码**：选择角色（用户/管理员）与账户有效期天数，生成后复制分发给新成员
- **公司数据库密码**：查看 / 创建 / 修改本公司数据库密码（新成员加入公司需填写该密码）
- **账号管理**：查看**自己创建的账号**（通过自己发出的邀请码注册的账号），延长有效期或清除账号；**账户到期后该成员无法登录**（登录时会有醒目提醒），延长后即可恢复

> 💡 修改公司数据库密码后，本公司所有成员自动生效，映射库数据自动迁移，无需其他操作。

### 3. 更换参考模板

参考模板在 Web 页面直接上传即可，无需修改配置文件。

> 💡 列结构（公式列、毛利率列等）全部由工具**自动从参考模板中识别**，不需要修改任何代码，也没有硬编码的列映射规则。

### 4. 修改图片行高

如果觉得结果表格中图片太大或太小，用记事本打开 `backend/config.py`，找到：

```python
IMAGE_ROW_HEIGHT_PT = 60    # 行高（磅），改这个数字
IMAGE_MARGIN_PT = 4         # 图片与表格边框的间距
```

- 改大 → 图片更大、行更高
- 改小 → 图片更小、行更矮

### 5. 映射历史记录管理

本工具会自动记录你对映射关系的每次调整，保存在项目 `data/映射历史记录_{key}.json` 文件中（按公司隔离键命名，不同公司数据互不可见）。以后处理类似表格时，系统会优先采用你之前设定的映射关系，**越用越智能**。

**工作原理：**

1. 匹配完成后，你可以在页面上手动调整映射关系（改目标列、新增映射、删除映射）
2. 点击「🚀 开始转换」时，系统会自动识别你做了哪些修改并记录下来
3. 下次上传表格并匹配时，历史记录会自动生效，优先使用你之前设定的映射

**重复数据处理：**

向映射库写入记录时，若检测到**原始列名已存在**（查重仅以原始列名为准），页面会弹出确认框，让你选择：

- **覆盖** — 用新记录替换库中同源列名的旧记录
- **跳过** — 保留库中原记录，不写入
- **取消** — 放弃本次写入

> 💡 数据文件统一存放在项目 `data/` 目录（映射匹配库、API Key 等），随项目整体拷贝/备份时数据一并携带。
>
> 💡 如需清空所有历史记录，删除该文件即可。也可在「映射匹配库」页面用 Excel 导出备份、Excel/CSV 导入恢复。

### 6. 命令行批量转换

除了 Web 界面，也可以用命令行处理文件：

```bash
# 单个文件
python backend/main.py 表/参考.xlsx 表/客户表格.xlsx

# 多个文件
python backend/main.py 表/参考.xlsx 表/客户A.xlsx 表/客户B.xlsx

# 不用 AI（本地智能匹配）
python backend/main.py 表/参考.xlsx 表/客户表格.xlsx --no-ai

# 指定输出文件（仅单文件时）
python backend/main.py 表/参考.xlsx 表/客户表格.xlsx -o data/输出/结果.xlsx
```

> 💡 命令行模式适合定时任务或脚本化批量处理，**复用与网页端完全相同的转换逻辑**（三级匹配、公式处理、图片复制等），结果一致。
>
> 💡 `--no-ai` 模式使用内置本地匹配引擎，通过列名语义分析、领域关键词和数据类型推断进行智能匹配，无需网络连接。

**技术栈**：

- **后端**: Python FastAPI + uvicorn (ASGI 服务器)
- **前端**: React 19 + Vite 8 (开发服务器)
- **API 通信**: 前端通过 Vite proxy 代理 `/api` 请求到后端
- **登录会话**: `Authorization: Bearer <token>`（登录后签发，登出/过期失效）
- **匿名会话**: `X-Session-Id` 请求头（前端 localStorage 持久化）
- **API 文档**: 自动生成于 `http://127.0.0.1:8004/docs`

**端口配置**：

| 服务 | 端口 | 说明 |
| ------ | ------ | ------ |
| FastAPI 后端 | 8004 | REST API + 自动文档（生产仅 `127.0.0.1`，由 Nginx 反代） |
| React 前端 (Vite) | 3002 | 本地开发服务器，带 HMR |
| Nginx（生产） | 8080 | 生产对外入口，托管 `frontend/dist` + 反代 `/api` |

> 本地开发：前端 `3002` → 代理 `/api` → 后端 `8004`；生产：Nginx `8080` 统一入口 → 反代 `/api` → 后端 `8004`。
