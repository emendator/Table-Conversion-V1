## 这个工具是干什么的

你有一批**客户发来的表格**，每张表格的列名、列顺序都不一样。

公司有一份**标准的参考模板**（「参考.xlsx」），规定了统一的列名和格式。

这个工具就是帮你**自动把客户的表格转成公司标准格式**，省去手动复制粘贴的麻烦。

**它能做什么：**

- 🤖 用 DeepSeek V4 Flash AI 自动匹配列名——不仅看表头，还会对比**列里的实际数据**来精准判断
- 🧩 **不用 AI 也能智能匹配**——内置本地匹配引擎，通过列名语义、领域关键词、数据类型综合评分，离线也能用
- 🧠 **映射历史自动学习**——你手动调整过的映射关系会被记录下来，下次自动优先使用，越用越准
- �📦 **一次上传多个表格**，自动合并成一个结果文件
- 🖼️ 自动把客户表格里的产品图片搬到结果表格中，缩放居中
- 📝 自动识别参考模板里的 Excel 公式列，只填数据不破坏公式
- 📊 转换完成后可**在线预览**原始表格和结果表格的对比
- 🔧 映射关系**可手动调整**，源列和目标列都能改

## 准备工作（只需做一次）

### 1. 安装 Python

如果电脑上还没有 Python，请从 [python.org](https://www.python.org/downloads/) 下载安装。

> ⚠️ 安装时**一定要勾选**「Add Python to PATH」！

### 2. 双击启动

在项目文件夹里找到 `启动.bat`，**双击运行**。它会自动完成以下操作：

1. 检查 Python 依赖（fastapi、pandas、openpyxl 等）
2. 检查 Node.js 前端依赖（无需手动安装）
3. 启动后端 FastAPI 服务（端口 8004）
4. 启动前端 React 开发服务器（端口 3002）
5. 打开浏览器到 `http://127.0.0.1:3002`

> 如果双击没反应，右键选择「以管理员身份运行」。

### 3. 看到这个界面就成功了

```
============================================================
  📊 表格转换工具 - React + FastAPI 架构
============================================================
  🔧 后端 API 服务: http://127.0.0.1:8004
  🖥️  前端界面:    http://127.0.0.1:3002
  📖 API 文档:     http://127.0.0.1:8004/docs
============================================================
```

打开浏览器，在地址栏输入 `http://127.0.0.1:3002`，就能看到操作页面。

### 4. 文件放哪里

根据使用方式不同：

- **🖥️ Web 界面（推荐）**：直接在页面上传即可，文件无需放入特定文件夹。
  - 上传后文件会暂存在 `backend/uploads/` 目录，关闭工具时自动清理。
  - 参考模板只需上传一次，后续可随时切换。
- **⌨️ 命令行**：参考模板默认放在 `表/参考.xlsx`，原始表格可放在任意位置。
  - 例如：`python backend/main.py 表/参考.xlsx D:\客户文件\客户A.xlsx`
  - 原始表格也可放到 `表/` 目录下统一管理。

> 💡 `表/` 目录是 CLI 模式下的默认查找路径，Web 模式下文件位置不受限制。

## 如何使用（图文教程）

### 第一步：上传文件

打开页面后，你会看到两个上传区域：

| 左侧 | 右侧 |
|------|------|
| **原始表格**（客户发来的） | **参考模板**（公司标准格式） |

**操作方法（任选一种）：**

- 直接把文件**拖拽**到对应的区域
- 或者**点击**上传区域，在弹出的窗口中选择文件
- 左侧原始表格可以**一次选择多个文件**（按住 Ctrl 多选），或后续点击「➕ 添加文件」追加

上传成功后，会显示文件列表信息。

> 💡 参考模板只需上传一次，所有原始表格都按这个模板转换。

### 第二步：智能列匹配

两个区域都有文件后，页面会出现「🤖 AI 智能列匹配」区域。

1. **匹配方式选择**：
   - 打开「使用 DeepSeek AI 匹配」开关 → 使用 AI 进行语义匹配（更精准）
   - 关闭开关 → 使用内置本地匹配引擎（离线可用，无需网络）
2. 点击 **「🔍 开始匹配」** 按钮
3. 系统会**同时分析表头名称和列里的实际数据**，进行智能配对

> 💡 **本地匹配**内置了 9 大领域词典（型号、价格、图片、品牌、品类等）和数据类型推断，即使不用 AI 也能得到合理的匹配结果。

匹配完成后，你会看到一个映射表格：

```
匹配度    原始表格列名        →    参考表格列名        操作
─────────────────────────────────────────────────────────
  高      大客户代发价        →    新进货价           删除
  高      序号               →    序号               删除
  中      产品               →    型号               删除
  高      图片               →    图片               删除
```

### 第三步：检查和调整

- 如果某条匹配**不对**，点击下拉框手动更改
- 如果 AI **漏掉了某列**，点击「➕ 手动添加映射」补充
- 不需要的映射点击「删除」
- **源列名**（左侧）和**目标列名**（右侧）都可以点击下拉框切换

### 第四步：执行转换

确认映射无误后，点击 **「🚀 开始转换」** 按钮。

几秒后转换完成，页面会显示：

- 📥 **下载转换结果** — 点击下载最终表格
- 🔍 **表格内容预览** — 可以在页面上直接查看结果

### 第五步：检查结果

打开下载的 `.xlsx` 文件，检查：

1. 数据是否正确填入对应列
2. 图片是否正常显示
3. 公式列是否自动计算

> 💡 如果结果不理想，可以点击「🔄 转换新文件」重新来过。

## 常见问题

### Q: AI 匹配结果是 0 个列？

可能是网络问题导致 AI 返回不完整。请尝试：

1. **关闭 AI 开关再匹配**——本地匹配引擎无需网络，也能给出合理的匹配结果
2. 检查电脑是否能正常访问 `https://api.deepseek.com`
3. 重试一次

### Q: 转换后图片位置不对？

这通常是源文件中图片的锚点格式特殊。工具已支持两种主流图片格式（单元格嵌入和浮动锚点），如仍有问题请在 Excel 中将源文件另存为 `.xlsx` 格式后重试。

### Q: 点击上传没反应？

1. 刷新页面（Ctrl+F5 强制刷新）
2. 确认终端窗口没有关闭（后端和前端两个服务必须保持运行）
3. 如果提示网络错误，说明后端 FastAPI 服务已停止。
   - 重新双击 `启动.bat`
   - 或用任务管理器杀掉所有 `python.exe` 和 `node.exe` 进程后再启动

### Q: 转换后有些列是空的？

检查映射表，确认所有需要的列都已正确配对。必要时使用「手动添加映射」补充。

### Q: 多个原始表格能一起处理吗？

可以！上传时按住 Ctrl 多选文件，或上传后点「➕ 添加文件」追加。工具会自动逐个匹配并合并成一个结果文件。

### Q: 换了一份完全不同的参考模板能用吗？

能。**公式列、毛利率列等全部由工具自动从参考模板中识别**，不需要修改任何代码。

### Q: 映射历史记录存在哪里？能清空吗？

映射历史记录保存在 `backend/映射历史记录.json` 文件中。你可以直接用记事本打开查看或编辑。如果想清空所有历史记录，删除这个文件即可。

### Q: 关闭 AI 匹配后匹配效果好吗？

本地匹配引擎通过**列名语义分析 + 领域关键词匹配 + 数据类型推断 + 字符相似度**的综合评分算法进行匹配。对于常见的列名（序号、图片、型号、价格、品牌、备注等）准确率很高。如果遇到匹配不准的情况，可以手动调整，调整结果会被保存到历史记录中，下次自动优先使用。

## 简单维护指南

> 💡 **不需要懂编程就能修改以下配置。** 用记事本打开对应文件，修改数字或文字，保存即可。

### 1. 修改毛利率

用记事本打开 `backend/config.py`，找到这一行：

```python
MARGIN_RATE = 0.10  # 10%
```

把 `0.10` 改成你需要的值，比如 `0.15` 就是 15%。

### 2. 更换参考模板

参考模板在 Web 页面直接上传即可，无需修改配置文件。

### 3. 添加新的自动匹配规则

比如客户表格里经常出现「成本价」这个词，你想让它自动匹配到「新进货价」：

用记事本打开 `backend/config.py`，在 `SPECIAL_MAPPINGS` 里加一行：

```python
SPECIAL_MAPPINGS = {
    "代发": "新进货价",
    "成本价": "新进货价",   # ← 新增这一行
}
```

### 4. 修改 DeepSeek 模型与密钥

用记事本打开 `backend/config.py`，找到开头这几行：

```python
DEEPSEEK_API_KEY = "sk-xxxxxxxxxxxxxxxx"   # API 密钥
DEEPSEEK_MODEL = "deepseek-v4-flash"       # 模型名称
```

- **API 密钥过期了**：把引号里的 `sk-...` 替换成新的
- **想换模型**：把 `deepseek-v4-Flash` 改成其他模型名（如 `deepseek-v4-pro`）

可用的模型名（参见 [DeepSeek 官方文档](https://api-docs.deepseek.com/zh-cn/)）：

- `deepseek-v4-flash` — 快速响应，适合日常使用
- `deepseek-v4-pro` — 更精准，响应稍慢

> ⚠️ **安全提醒**：API 密钥是花钱买的，不要发给别人！

### 4.1. API 调用费用说明

本工具每次使用 DeepSeek AI 进行列名匹配都会消耗 API 额度，按 Token 用量计费。以下是当前 DeepSeek 模型价格（来自 [DeepSeek 官方定价页面](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)）：

| 模型 | 百万 tokens 输入（缓存命中） | 百万 tokens 输入（缓存未命中） | 百万 tokens 输出 |
|------|:---:|:---:|:---:|
| `deepseek-v4-flash`（默认） | 0.02 元 | 1 元 | 2 元 |
| `deepseek-v4-pro` | 0.025 元 | 3 元 | 6 元 |

> 💡 **实际使用成本很低**：一次典型的列名匹配任务大约消耗 1,000～3,000 tokens（输入为主），按 `deepseek-v4-flash` 计算，每次匹配费用约 **0.001～0.003 元**，几乎可以忽略不计。
>
> 如果每次匹配都命中缓存（常见于重复或相似的表格），费用会更低（约 0.00002～0.00006 元）。

**扣费规则**：费用 = Token 消耗量 × 模型单价，从充值余额或赠送余额中扣除（优先扣赠送余额）。更多详情请查看 [DeepSeek 定价页面](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)。

### 4.2. 映射历史记录管理

本工具会自动记录你对映射关系的每次手动调整，保存在 `映射历史记录.json` 文件中。以后处理类似表格时，系统会优先采用你之前设定的映射关系，**越用越智能**。

**工作原理：**

1. 匹配完成后，你可以在页面上手动调整映射关系（改目标列、新增映射、删除映射）
2. 点击「🚀 开始转换」时，系统会自动识别你做了哪些修改并记录下来
3. 下次上传表格并匹配时，历史记录会自动生效，优先使用你之前设定的映射

**示例：**

第一次使用，AI 将「产品」匹配到「快查型号」，但你需要它匹配到「商品名称」。你手动修改后，系统会记住这个调整。下次再有「产品」列时，会自动匹配到「商品名称」。

> 💡 如需清空所有历史记录，直接删除 `backend/映射历史记录.json` 文件即可。

### 5. 修改图片行高

如果觉得结果表格中图片太大或太小，用记事本打开 `backend/config.py`，找到：

```python
IMAGE_ROW_HEIGHT_PT = 60    # 行高（磅），改这个数字
IMAGE_MARGIN_PT = 4         # 图片与表格边框的间距
```

- 改大 → 图片更大、行更高
- 改小 → 图片更小、行更矮

### 6. 命令行批量转换

除了 Web 界面，也可以用命令行处理文件：

```bash
# 单个文件
python backend/main.py 表/参考.xlsx 表/客户表格.xlsx

# 多个文件
python backend/main.py 表/参考.xlsx 表/客户A.xlsx 表/客户B.xlsx

# 不用 AI（本地智能匹配）
python backend/main.py 表/参考.xlsx 表/客户表格.xlsx --no-ai
```

> 💡 命令行模式适合定时任务或脚本化批量处理。
>
> 💡 `--no-ai` 模式使用内置本地匹配引擎，通过列名语义分析、领域关键词和数据类型推断进行智能匹配，无需网络连接。

## 架构说明（v3.0 React + FastAPI）

```
表格转换/
├── backend/                  ← 🔧 后端 API 服务（FastAPI + uvicorn）
│   ├── app.py                # FastAPI 主应用，提供 /api/* 纯 REST 接口
│   ├── config.py             # 配置文件（API 密钥、路径、业务规则）
│   ├── table_converter.py    # 核心转换逻辑
│   ├── deepseek_matcher.py   # AI 列名匹配引擎
│   ├── mapping_history.py    # 映射历史记录
│   ├── main.py               # 命令行批量转换入口
│   ├── requirements.txt      # Python 依赖（fastapi / uvicorn 等）
│   ├── 映射历史记录.json     # 映射历史持久化文件
│   ├── 输出/                 # 转换结果输出目录
│   └── uploads/              # 上传临时文件（自动清理）
├── frontend/                 ← 🖥️ 独立前端（React 19 + Vite 8）
│   ├── src/
│   │   ├── App.jsx           # 主应用组件（4 步骤流程）
│   │   ├── App.css           # 完整样式表
│   │   ├── api.js            # API 调用模块（自动管理 session）
│   │   └── main.jsx          # React 入口
│   ├── index.html            # 页面模板
│   ├── vite.config.js        # Vite 配置（端口 3002 + /api 代理）
│   └── package.json          # Node.js 依赖
├── 表/                       # 参考模板和原始表格存放目录
├── 启动.bat                  # 一键启动（同时启动前后端）
├── README.md                 # 本文件
└── 工作日报/                 # 开发工作日报
```

**技术栈**：

- **后端**: Python FastAPI + uvicorn (ASGI 服务器)
- **前端**: React 19 + Vite 8 (开发服务器)
- **API 通信**: 前端通过 Vite proxy 代理 `/api` 请求到后端
- **会话管理**: `X-Session-Id` 请求头（前端 localStorage 持久化）
- **API 文档**: 自动生成于 `http://127.0.0.1:8004/docs`

**端口配置**：

| 服务 | 端口 | 说明 |
|------|------|------|
| FastAPI 后端 | 8004 | REST API + 自动文档 |
| React 前端 (Vite) | 3002 | 开发服务器，带 HMR |
